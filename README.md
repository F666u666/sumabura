# スマブラ収支

スマブラの収支を記録・分析するシングルファイルWebアプリ。`index.html` 1枚で完結（HTML/CSS/JS＋データすべて内包、オフライン動作）。

- データはブラウザの localStorage に保存（端末内のみ）
- 初回起動時に過去152件＋αの記録を自動投入（`SEED`）
- ホーム / 分析 / 記録 の3タブ（ボトムナビ）

## デプロイ
Vercel に静的サイトとして配置。`index.html` がそのままルートで配信される。
このリポジトリに push すると自動デプロイされる。

## スマホ優先のデザイン改修案

- ホームは累計収支を先頭に表示し、そのすぐ下で今日の金額と符号を入力できます。
- 累計額と今月の収支を並べ、累計グラフに金額の目盛り、ゼロ基準線、期間切り替え（直近12件・全期間）を追加。
- 白・墨色・くすみ青で統一。勝率と勝ち負けの内訳は細い横棒で表示。PCでは累計収支の下に入力と推移を並べます。
- 入力とデータ管理のパネルは [Transitions.dev — Panel reveal](https://transitions.dev/transitions/panel-reveal/) を適用。動きを減らすOS設定に対応。
- 保存キー、初期データ、入出力形式は従来どおり。別ディレクトリのプレビューは架空のデータを使用。
